# Changelog for version 2.1.306

## Summary

This release fixes authentication for `claude -p` launched inside cloud sessions without the session’s environment variables. It also preserves the original API error and avoids unnecessary compaction in sessions with many MCP tools.

## Other Changes

- Fixed `claude -p` reporting `Not logged in` inside cloud sessions when launched without inherited session environment variables, by allowing it to read the session’s saved credentials.
- Fixed unrelated API errors triggering a retry without deferred MCP tools, which could replace the original error with `prompt is too long` and cause unnecessary compaction.
