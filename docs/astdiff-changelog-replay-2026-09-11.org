* Conclusion

This candidate is a real diff improvement and is now the service-selected
binary. It does not make prose generation dependable by itself. The next gate
should verify required evidence coverage and reject a no-change conclusion
when the filtered diff contains substantive old-to-new changes. Model strength
can then be evaluated against a fixed evidence set rather than used as the
only correctness mechanism.
