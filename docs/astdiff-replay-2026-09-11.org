* Interpretation and next experiment

This was one retry per version using production's =gpt-5.6-terra= at medium
reasoning, the existing system prompt, and annotation disabled. No expected
findings were supplied to the agents. It is an operational replay, not a
statistical model benchmark or a blinded evaluation: agents could read older
answers and did so. It also includes the already-applied filtering correction,
so any difference would not isolate the effect of the binary upgrade alone.

The next controlled replay should exclude the target version's existing
changelog from the agent's inputs, require explicit old/new evidence for each
candidate and for a no-change conclusion, and reject unsupported claims that
all structural changes are rebundling. The Bun comparison also needs better
module/declaration correspondence; installing the newer matcher did not fix
the observed getter mispairing. A stronger model can be compared once that
replay has a fixed evidence set and explicit correctness checks.

No retry output was committed, pushed or posted. The scheduler remains enabled
and uses the pinned build for future diffs.
